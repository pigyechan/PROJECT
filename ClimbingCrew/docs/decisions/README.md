# 설계 결정 기록 (Decision Log)

이 폴더는 "왜 이렇게 만들었는지"를 남겨두는 곳이다. `CLAUDE.md`가 "지금 어떤 상태인가"를 보여주는 문서라면, 여긴 "그 상태에 왜 도달했는가"를 남긴다.

## 규칙

- **파일 하나 = 하루** (`2026-08-12.md`처럼 날짜로 이름 붙인다). 그날 나온 결정들을 그 안에 소제목(`## 제목`)으로 쌓는다. 결정마다 파일을 나누면 파일 수가 너무 늘어나서, 날짜 단위로 묶는다.
- 나중에 결정이 뒤집혀도 지난 글은 지우거나 고치지 않는다. 새 날짜 파일에 새로 쓰고, 뒤집힌 기존 항목 위에 "→ 2026-XX-XX에서 재검토됨" 한 줄만 추가한다. 지난 판단의 맥락 자체가 자산이라 지우지 않는다.
- 형식은 아래 템플릿을 따르되, 무겁게 쓰지 않는다. 배경/결정/이유/기각한 대안 네 항목이면 충분하다.

## 템플릿 (하루 파일 안의 결정 하나)

```markdown
## 제목

### 배경
왜 이 결정이 필요했는지

### 결정
무엇을 하기로 했는지

### 이유
왜 이렇게 결정했는지

### 기각한 대안
다른 어떤 선택지가 있었고, 왜 안 골랐는지
```
